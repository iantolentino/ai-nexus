# AI Nexus framework repository

`_brain/AI_BRAIN.md` is the universal controller for this repository. Before changing the framework, run `_brain/tools/select-context.ps1 -Intent framework-maintenance -NoManifest` and read only its selected context.

This repository distributes the `_brain/` template to other projects. Use `FRAMEWORK_STATE.md` as this repository's state; template `CURRENT_STATE.md` is for installed projects. Preserve template knowledge unless the user explicitly authorizes its removal.
